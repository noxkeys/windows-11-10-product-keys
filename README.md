# Windows 11 & 10 Product Keys

> **Important:** None of the keys below will **activate** Windows. They are Microsoft-published **generic** keys.
> - **Generic install (RTM) keys** pick which edition gets installed.
> - **KMS client keys (GVLKs)** only activate against an organisation's own KMS server.
>
> A genuine licence is still required to activate. See [How to activate legally](#how-to-activate-windows-legally) below.

## Which key do I need?

| You want to…                                              | Use                                   |
| --------------------------------------------------------- | ------------------------------------- |
| Install a specific edition (e.g. Pro instead of Home)     | Generic install key                   |
| Upgrade Home → Pro, then activate with your own licence   | Generic Pro key, then your retail key |
| Activate PCs on a company network that runs a KMS host    | KMS client key (GVLK)                 |
| Actually activate a personal PC                           | A **genuine retail / OEM licence**    |

## Useful commands (slmgr)

Run these in **Command Prompt (Admin)**:

```bat
:: Show the current edition
DISM /Online /Get-CurrentEdition

:: Install a product key (generic or your genuine key)
slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

:: Activate online
slmgr /ato

:: Show licence details (channel: Retail / OEM / Volume)
slmgr /dli
slmgr /dlv

:: Check whether activation is permanent
slmgr /xpr

:: Remove the current key
slmgr /upk
slmgr /cpky
```

**Upgrade Home → Pro without reinstalling:**
Go to *Settings → System → Activation → Change product key* and enter the generic Pro key `VK7JG-NPHTM-C97JM-9MPGT-3V66T`. Windows upgrades the edition, and you then activate it with your genuine Pro key.

## Common errors & fixes

| Error code   | Meaning                                    | Fix                                                        |
| ------------ | ------------------------------------------ | ---------------------------------------------------------- |
| `0xC004F074` | No KMS server could be contacted           | You used a GVLK on a home PC. Install a retail key instead |
| `0xC004C003` | The product key was blocked or invalid     | Use a genuine key from an authorised seller                |
| `0xC004F050` | The product key is invalid for this edition | Make sure the key edition matches (Home vs Pro)            |
| `0x803F7001` | No valid licence found                     | Enter a genuine product key under Activation               |
| `0xC004C008` | The key has been used too many times       | Contact your seller for a replacement                      |

## How to activate Windows legally

The generic keys above **install** Windows, but they do not license it. To activate permanently you need a genuine key:

- **Windows 11 Pro / Home**: retail keys for lifetime activation
- **Windows Server 2025 / 2022 / 2019**: Standard & Datacenter
- **Microsoft Office 2024 / 2021 Professional Plus**

## FAQ

**Are these keys free to use?**
Yes. Microsoft publishes them openly. They only install or select an edition and never activate a personal PC.

**Why does Windows say "Activate Windows" after using a generic key?**
That is the expected result. Generic keys are not licences. Enter a genuine retail or OEM key to remove the watermark.

**Can I use a KMS key at home?**
No. KMS keys need a corporate KMS host server. On a home PC they fail with `0xC004F074`.

**Is a Windows 10 key valid for Windows 11?**
Yes. Genuine Windows 10 keys of the same edition activate Windows 11.
